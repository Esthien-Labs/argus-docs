# Esthien Labs

Esthien Labs is a chipset company building the Argus product family - safety-supervised inference from software through custom silicon.

## Products

| Product | Status | Description |
|---------|--------|-------------|
| **Argus SDK** | Available | Software safety reference |
| **Argus Dev Kit** | In development | FPGA-accelerated hardware |
| **Argus ASIC** | Planned | Dedicated silicon (EARG-001) |

## The Argus platform

Argus enforces bounded command authority for autonomous systems. The same safety logic and evidence format run across software, FPGA, and ASIC - validated at each stage before advancing.

### Evidence-driven development

- Every claim requires matching evidence
- Simulation, FPGA, and silicon evidence are tracked separately
- No unverified claims in product documentation

### Standards-mapped output

Reports cite specific standard sections:
- ISO 3691-4 (Industrial trucks)
- ISO 26262 (Road vehicles)
- IEC 62304 (Medical devices)
- IEC 61508 (Functional safety)
